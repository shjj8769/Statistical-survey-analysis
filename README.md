# 서울시 고립·은둔 청년 실태조사 분석

> 2021 서울시 고립·은둔 청년 실태조사 가구 자료를 SPSS 교차분석과 카이제곱 검정으로 분석한 통계 보고서

| 항목 | 내용 |
| --- | --- |
| 기간 | 2025.03 – 2025.05 (2025-1학기 통계조사실습, 한신대학교 응용통계학과) |
| 형태 | 2인 공동 분석 보고서 (194쪽) |
| 데이터 | 2021 서울시 고립·은둔 청년 실태조사 (가구), 분석 표본 6,926 |
| 사용 기술 | SPSS (교차분석, 카이제곱 동일성 검정) |

![분석 방법](https://shjj8769.github.io/assets/slides/survey/slide-02.webp)

## 조사 개요

- **대상**: 서울시 만 19~39세 청년 가구원이 있는 가구 (가족이 응답)
- **목적**: 고립·은둔 청년과 가족의 실태, 가족의 어려움과 정책 수요 파악
- **고립·은둔 해당**: 326가구, 모집단 추정 비율 4.5%
- **A영역**: 고립·은둔 여부 확인 (생활 실태, 교류, 기간과 원인)
- **B영역**: 가족의 어려움 및 필요사항 (생활 패턴, 자기관리, 식사, 가족의 부담과 노력, 필요 지원)

## 분석 방법

1. 문항별 응답 분포 산출
2. 유사 응답 범주 통합 (예: 5점 척도 → 3범주 + 모름)
3. 응답자 특성 8개별 교차분석
4. 카이제곱 동일성 검정 (유의수준 0.05)
5. 문항별 결론 도출

**교차분석 변수 (8개)**: 고립·은둔 여부, 성별, 연령대, 가구원 수, 청년 가구원 성별, 청년 가구원 연령, 거주 주택유형, 월 평균 가구소득

### 분석 예시: B1-1 "평소 가족과 친밀하게 지내는 편이다" (%)

| 구분 | 그렇지 않다 | 보통이다 | 그렇다 | 유의확률 |
| --- | --- | --- | --- | --- |
| 고립·은둔 | 27.4 | 22.9 | 45.7 | <0.0001 |
| 미해당 | 9.2 | 27.7 | 61.5 | |

→ "친밀하지 않다" 응답이 고립·은둔 가구에서 약 3배 높음

## 주요 결과 (B영역)

| 문항 | 결과 |
| --- | --- |
| B3·B4 식사 | 고립·은둔일수록 식사 횟수가 적고 혼자 해결 |
| B6 가족의 부담 | 연령대가 높을수록 '답답함' 증가, 성별 차이 유의 (p<0.0001) |
| B7 가족의 노력 | 연령대가 높을수록 취업 권유 증가 |
| B8 본인 필요 지원 | 고립·은둔 가구는 심리 상담 요구 14.0% (미해당 5.5%) |
| B9 가족 필요 지원 | 고립·은둔 가구는 이해 프로그램 요구 21.9% (미해당 14.9%) |

## 결론 및 정책적 시사점

고립·은둔은 개인의 심리 문제만이 아니라 **가족 구조·경제 여건·사회적 자원 접근성이 상호작용하는 복합 현상**으로 나타났습니다.

- **가족 중심 개입**: 청년뿐 아니라 가족 전체를 상담·지원 대상으로
- **소득·주거 기반 맞춤 지원**: 저소득·불안정 주거 가구 우선 지원
- **연령대별 차등 접근**: 20대 이하와 30대 이상의 사회 진입기 차이 반영
- **긴급 대응·연결망 복원**: 심리·정서 응급 대응과 지역 관계망 회복
